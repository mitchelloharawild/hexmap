# Australian federal 2022 election map and winner

Australian federal 2022 election map and winner

## Usage

``` r
aec2022
```

## Format

An object of class `sf` (inherits from `tbl_df`, `tbl`, `data.frame`)
with 151 rows and 6 columns.

## Source

The data incorporates electoral boundary data and election result data
from © Commonwealth of Australia (Australian Electoral Commission) 2022
<https://www.aec.gov.au/>
